# Decisions

Short, dated records of package-level decisions: what `@vibexp/design-system`
owns, what it doesn't, and why. They are read by humans and AI sessions before
reopening a question.

- One file per decision: `NNNN-kebab-title.md`, numbered in order.
- Header: **Status** (`Accepted` · `Superseded by NNNN`), date, the issue, and
  the commit/version the evidence was measured against.
- Never rewrite an accepted decision's verdict. Add a new record that
  supersedes it and update the old record's Status line.
